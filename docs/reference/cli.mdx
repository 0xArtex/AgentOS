The complete command surface of `@palmyr/cli`. Costs are paid in USDC over [x402](/concepts/payments) at request time; actions marked **free** require no payment. For prose and examples, follow the per-service links.

```bash
npm i -g @palmyr/cli      # Node.js 18+
palmyr <command> --help    # discover any subcommand
```

## Output modes

The CLI defaults to an agent-friendly JSON contract — raw JSON on stdout, structured errors and exit codes — and renders a human-readable interface only when you run it in a terminal.

- **Interactive (TTY)** — menus, spinners, colour.
- **Agent mode** — raw JSON on stdout, NDJSON for streaming, single-line `{error, exitCode}` JSON on stderr, no ANSI.

Agent mode turns on when stdout is not a TTY, when you pass `--json`, or when `PALMYR_JSON=1` is set. See [For AI Agents](/for-agents).

## Wallet

All wallet operations except `addresses`, `api-key`, and `config` run locally with no server contact. Full guide: [Wallets & funding](/concepts/wallets).

| Command | Cost | Description |
|---|---|---|
| `wallet create [--name N] [--tag T] [--count N]` | free | Create a wallet. Requires `--passphrase`, `PALMYR_WALLET_PASSPHRASE`, or `--session-only`. |
| `wallet import --mnemonic "..."` | free | Restore from a BIP-39 seed. |
| `wallet rekey <ID> --passphrase P` | free | Add or rotate the scrypt passphrase fallback. |
| `wallet list [--tag T]` | free | List wallets in the local vault. |
| `wallet info <ID>` | free | Show one wallet (id, addresses, mode, tag). |
| `wallet tags` | free | List tags with counts and chains. |
| `wallet tag <ID> <TAG>` | free | Assign, change, or clear a tag (`--clear`). |
| `wallet tag-delete <TAG> --confirm` | free | Cascade-delete every wallet under a tag. |
| `wallet use <ID> --chain <chain>` | free | Set the default payer and payment chain. |
| `wallet addresses <ID>` | API | Server-derived multi-chain addresses. |
| `wallet sign-message <ID> --msg "..."` | free | Sign an arbitrary message offline. |
| `wallet api-key <ID> [--name N]` | API | Mint an agent API key bound to the wallet. |
| `wallet export <ID> --confirm` | free | Print the mnemonic (guarded by `--confirm`). |

## Trading

Swaps route from your wallet to Jupiter (Solana) and ParaSwap (Base). No Palmyr fee for the swap. Full guide: [Trading](/services/trading).

| Command | Description |
|---|---|
| `wallet buy solana <CA> --amount 0.5sol --thesis "..."` | Open a Solana position. Exit flags: `--cut`, `--tp`, `--trail`, `--time-limit`, `--protected`. |
| `wallet buy base <0xToken> --amount 0.01eth --thesis "..."` | Open a Base position. |
| `wallet sell solana <CA> --percent 50 --reason "..."` | Sell N% (FIFO realized PnL); auto-closes at 100%. |
| `wallet sell base <0xToken> --percent 50 --reason "..."` | Sell N% on Base (auto-handles ERC20 approval). |
| `wallet positions [--chain X] [--all]` | List open (and with `--all`, closed) positions. |
| `wallet position <CA>` | Full detail: thesis, exit plan, sells, PnL. |
| `wallet sync [--wallet Y]` | Reconcile on-chain balances; refresh unrealized PnL. |
| `wallet pnl [--by chain] [--since DATE]` | Aggregate realized + unrealized, with USD total. |
| `wallet journal add <CA> --note "..."` | Append a trade note (`journal show` to read). |
| `wallet watch add <CA> --trigger "..."` | Append a watchlist entry (`watch list` to read). |
| `wallet brief <CA> [--evaluate]` | Position brief; `--evaluate` runs an LLM thesis check. |
| `wallet daemon start [--interval N] [--auto]` | Background monitor; auto-exits on triggers with `--auto`. Also `tick` / `stop` / `status`. |
| `wallet triggers [--clear]` | List pending trigger fires. |
| `wallet cohort buy <CHAIN> <CA> --total <amt> --wallets a,b,c` | Split one decision across N wallets. |
| `wallet template list` | Manage YAML strategy templates (`show` / `path` / `delete`). |
| `wallet evm-quote <SRC> <DST> --amount <raw>` | Get a Base swap quote without signing. |
| `wallet trading-keystore init [--count N]` | Optional power-user keystore (`unlock` / `lock` / `list` / `status` / `derive` / `export`). |

## Configuration

Config lives in `~/.palmyr/config.json`; environment variables override file values.

| Variable | Purpose |
|---|---|
| `PALMYR_API` | Override the API endpoint. |
| `PALMYR_TOKEN` / `PALMYR_API_KEY` | Bearer token for authenticated routes. |
| `PALMYR_PAY_WALLET` | Force a specific wallet ID for x402 payment. |
| `PALMYR_WALLET_PATH` | Override the vault directory. |
| `PALMYR_WALLET_PASSPHRASE` | Vault decryption passphrase / recovery fallback. |
| `PALMYR_JSON` | Set to `1` to force agent (JSON) output. |

## Exit codes

| Code | Constant | Meaning |
|---|---|---|
| `0` | `OK` | Success |
| `1` | `GENERAL` | Uncategorised failure |
| `2` | `BAD_INPUT` | Invalid command, flag, or argument |
| `3` | `AUTH_FAIL` | 401, or missing token |
| `4` | `NOT_FOUND` | 404, or unknown local resource |
| `5` | `NETWORK` | DNS, connection, or transport failure |
| `6` | `PAYMENT` | 402, or x402 signing was rejected |
| `7` | `SECURITY` | Wallet integrity check failed |

## File layout

```text
~/.palmyr/
  config.json        resolved config (chains, defaults, vault path)
  wallet/            encrypted wallet files, key metadata, spend ledgers
  secrets/           Windows DPAPI fallback (macOS/Linux use the OS keychain)
  data/              local cache of phones, inboxes, servers, domains
  trading/           positions, trades, journal, watchlist, templates
  memory/notes.md    output of palmyr note
```

Wallet files contain only ciphertext; the decryption key lives in your OS credential store.
