Every Palmyr service and what each action costs. It's all **pay-per-action** in USDC, charged at request time over [x402](/concepts/payments) on Solana or Base — no subscriptions, no minimums, no monthly bills.

<Note>
  The prices below are the published list at the time of writing. For the authoritative, live list, run `palmyr pricing` (free) or call `GET /pricing`.
</Note>

## Free

Discovery and local work never cost anything: `search`, `info`, `pricing`, `health`, `status`, `note`, and **every local wallet operation** (create, import, rekey, tag, export, sign). `list` is free where it reads local state (wallets, TikTok and X accounts); the server-side listings are priced in the tables below.

## Cards

| Action | Cost |
|---|---|
| `buy` (prepaid Visa, exact balance $5–$1000) | dynamic: amount + 3% fee (min $0.50) |
| purchase poll | free |

The fee is on top of the card's face value — a $20 card costs $20.60 total. Failed purchases auto-refund.

## Trading

Trades route directly from your wallet to on-chain DEXs (Jupiter on Solana, ParaSwap on Base). **Palmyr charges no fee for the swap itself** — you pay network gas and the DEX's pricing. Position tracking, PnL, the daemon, journals, and templates are all local and free. See [Trading](/services/trading).

## TikTok

| Action | Cost |
|---|---|
| `connect` (QR hand-off, or `--local`) / `import` / `list` / `info` / `session` / `rename` / `tag` / `remove` / `totp` / `push` / `pull` / `draft` / `drafts` / `reject` / `logs` / `review` / `monitor` | free |
| `connect --server` | $0.01 |
| `list --server` | $0.001 |
| `login` | $0.02 |
| `post` / `schedule` / `approve` | $0.01 |
| `follow` / `like` / `delete` / `bio` / `name` | $0.001 |
| `pfp` | $0.005 |
| `analytics` | $0.005 (free when self-hosted) |
| `hooks` (your own accounts, or `--tag`) | $0.001 |
| `hooks --niche` | $0.05 |
| `series` / `scheduled` / `cancel` | $0.001 |
| `corpus niches` | free |
| `corpus refresh` | operator-only — no Palmyr charge |

`connect` is free when the login happens on your machine (the default QR hand-off, or `--local`); `connect --server` is the $0.01 path that logs in inside the account's own browser profile on the server. Same split on `list`: local is free, `--server` is $0.001 — the payment is what identifies your wallet.

`hooks` has two prices because it answers two different questions: $0.001 measures **your** accounts against their own median, $0.05 reports what is working in a niche across TikTok. `corpus refresh` pre-warms a niche and is operator-only (pool-admin signature); it pays the upstream collector directly, not Palmyr, and agents never need it — the server refreshes a stale niche itself when `hooks --niche` asks for one.
