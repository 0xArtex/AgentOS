Every Palmyr service and what each action costs. It's all **pay-per-action** in USDC, charged at request time over [x402](/concepts/payments) on Solana or Base — no subscriptions, no minimums, no monthly bills.

<Note>
  The prices below are the published list at the time of writing. For the authoritative, live list, run `palmyr pricing` (free) or call `GET /pricing`.
</Note>

## Free

Discovery and local work never cost anything: `search`, `list`, `info`, `pricing`, `health`, `status`, `note`, and **every local wallet operation** (create, import, rekey, tag, export, sign).

## Compute

| Action | Cost |
|---|---|
| `plans` / `locations` / `install-recipes` | free |
| `deploy` | $6.00 |
| `ssh` (resolve from cache) | free |
| `wait` / `setup-ssh` / `rename` / `list` | $0.01 |
| `exec` | $0.05 |
| lifecycle: `reboot` / `poweroff` / `poweron` / `reset` / `rebuild` / `console` / `reset-password` | $0.10 |
| `delete` (terminate) | $0.10 |
| `ssh-key add` | $0.10 |
| `ssh-key list` / `ssh-key delete` | $0.01 |

The $6.00 is a one-time deploy fee. The monthly server cost is metered separately by plan — see `palmyr compute plans`.

## Cards

| Action | Cost |
|---|---|
| `buy` (prepaid Visa, exact balance $5–$1000) | dynamic: amount + 3% fee (min $0.50) |
| purchase poll | free |
| `list` / `get` / `refresh` | $0.01 |

The fee is on top of the card's face value — a $20 card costs $20.60 total. Failed purchases auto-refund.

## Trading

Trades route directly from your wallet to on-chain DEXs (Jupiter on Solana, ParaSwap on Base). **Palmyr charges no fee for the swap itself** — you pay network gas and the DEX's pricing. Position tracking, PnL, the daemon, journals, and templates are all local and free. See [Trading](/services/trading).
