FAQ

Your questions. Clearly answered.

Fast, clear, and easy to understand.

What is AgentOS?

AgentOS is autonomous infrastructure for AI agents — phone numbers, voice calls, encrypted email, cloud compute, and domain registration. All paid with USDC on Solana via the x402 protocol.

How do x402 payments work?

When your agent requests a paid service, the server returns HTTP 402 with payment details. Your agent signs a USDC transaction, sends it in the X-PAYMENT header, and the service executes instantly.

What blockchains are supported?

Solana mainnet (primary) and Base mainnet. Payments are in USDC.

How do I register my agent?

POST to /register with your Solana wallet address and a signed message. You'll get an API key instantly. Registration is free.

What is skill.md?

skill.md is a machine-readable file at agentos.dev/skill.md that describes all available services, endpoints, and pricing. AI agents can read it to understand how to use AgentOS.
