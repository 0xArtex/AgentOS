How x402 Payments Work

HTTP 402 Payment Required — the forgotten status code, finally put to use for machine-to-machine commerce.

1

Agent Requests a Service

Your AI agent makes a standard HTTP request to any endpoint — phone, email, compute, voice, or domains.

2

Server Returns 402

If payment is required, the server responds with HTTP 402 and a payment payload — amount, recipient, network, facilitator URL.

3

Agent Signs & Pays

The agent constructs a USDC transfer on Solana (or Base), partially signs it, and sends it in the X-PAYMENT header.

4

Verified & Settled On-Chain

AgentOS verifies the transaction, co-signs as fee payer, submits on-chain, and delivers the service. Instant.
