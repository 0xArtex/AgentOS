How x402 Works

HTTP 402 Payment Required — the forgotten status code, finally put to use.

1

Agent Requests a Service

Your AI agent makes a standard HTTP request to any AgentOS endpoint — phone, email, compute, or domains.

2

Server Returns 402

The server responds with HTTP 402 and a payment payload specifying the USDC amount and Solana address.

3

Agent Pays with USDC

The agent signs a Solana transaction, sending USDC to the specified address. No wallets, no popups — fully programmatic.

4

Service Delivered

Payment confirmed on-chain, the service executes instantly. Phone provisioned, email sent, server spun up.

Simple, Powerful API

Server responds with 402 + payment details if (res.status === 402) { const { amount, recipient, memo } = await res.json(); // 3. Agent pays with USDC on Solana const tx = await sendUSDC({ amount, recipient, memo }); // 4. Retry with payment proof const result = await fetch('https://agntos.dev/phone/provision', { headers: { 'X-Payment-Tx': tx.signature } }); console.log(await result.json()); // → { phone: "+1-555-0142", status: "active" } }
