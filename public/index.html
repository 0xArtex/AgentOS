Protocol

How x402 Works

A simple HTTP-native payment protocol. No API keys. No accounts. Just sign and pay.

01

Request Service

Agent sends a standard HTTP request to any AgentOS endpoint.

02

Server Returns 402

Server responds with HTTP 402 and a payment requirement specifying the USDC amount.

03

Agent Signs & Pays

Agent signs a USDC transaction on Solana or Base and includes the signature in a retry.

04

Service Delivered

Payment verified on-chain. Service executes immediately. No middlemen, no delays.

Developer Experience

Simple to Integrate

TypeScript
// x402 payment flow — no API keys needed
const response = await fetch('https://agntos.dev/api/phone/provision', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ country: 'US', type: 'local' })
});

if (response.status === 402) {
  // Extract payment requirement
  const payment = response.headers.get('X-Payment');
  const { amount, recipient, chain } = JSON.parse(payment);

  // Sign USDC transfer on Solana
  const tx = await signUSDCTransfer(amount, recipient);

  // Retry with payment proof
  const result = await fetch('https://agntos.dev/api/phone/provision', {
    method: 'POST',
    headers: {
      'X-Payment-Signature': tx.signature,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ country: 'US', type: 'local' })
  });

  const phone = await result.json();
  console.log('Provisioned:', phone.number); // +1 (555) 123-4567
}

FAQ

Your Questions, Answered

What is AgentOS?

AgentOS is a cloud infrastructure platform built specifically for autonomous AI agents. It provides phone/SMS, email, compute, domains, identity, and reputation services — all accessible via HTTP and paid with USDC through the x402 payment protocol.

How do payments work?

AgentOS uses the x402 HTTP payment protocol. When an agent requests a paid service, the server returns HTTP 402 with payment details. The agent signs a USDC transaction on Solana or Base, then retries with payment proof. No API keys or accounts needed.

What chains are supported?

AgentOS supports USDC payments on Solana mainnet and Base mainnet. Both chains offer fast finality and low transaction fees, ideal for micropayments.

How do I register my agent?

Agent registration is free. Simply POST to the registration endpoint with your agent's wallet address and metadata. Your agent receives a verifiable on-chain identity that works across all AgentOS services.

What's skill.md?

skill.md is a machine-readable manifest that describes all AgentOS capabilities, endpoints, pricing, and payment requirements. AI agents can read it to understand how to use the platform autonomously — no documentation needed.
