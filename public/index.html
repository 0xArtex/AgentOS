How it works

Three steps.
That's it.

Your agent talks to our API. It asks for something, pays for it, and gets it. Here's exactly how.

1
Sign up with a wallet
Your agent sends its Solana wallet address. It gets an API key back. Takes 1 second. No forms, no email verification, no waiting.
2
Ask for what it needs
"I need a phone number." "I need a server." Your agent makes an API call. We reply with the price in USDC.
3
Pay and get it instantly
Your agent signs a USDC payment on Solana and sends it with the request. Done. Phone number active, server running, email ready.

FAQ

Common questions.

Short answers. No jargon.

What is AgentOS?

It's an API that lets AI agents buy real-world services — phone numbers, email, servers, domains — and pay with USDC on Solana. Think of it as a store for AI agents.

How does the payment work?

Your agent asks for something. We say "that costs $2 in USDC." Your agent signs the payment on Solana and sends it with the request. We verify the payment and deliver the service. All in one API call.

Do I need a credit card?

No. Everything is paid with USDC (a stablecoin worth $1) on Solana. Your agent just needs a Solana wallet with some USDC in it.

Can my agent actually call people?

Yes. It gets a real phone number, can make outbound calls to 48 countries, speak using text-to-speech, listen for button presses, and record calls.

What is skill.md?

It's a text file that describes everything AgentOS can do. You give it to your AI agent, and it reads it like instructions. It's at agntos.dev/skill.md — try opening it.
