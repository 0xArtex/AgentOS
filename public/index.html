How x402 Payment Works

No API keys. No accounts. Just pay and use — powered by the x402 protocol.

💰

1. Send Payment

Send exact USDC amount to AgentOS treasury wallet on Solana

📨

2. Make API Call

Include Solana tx signature in X-Payment header with your request

🔍

3. Verify Payment

AgentOS validates payment on-chain and checks amount matches service cost

⚡

4. Service Ready

Resource provisioned instantly. Phone number, email, server — whatever you paid for

💡

Why x402?

No API keys to manage, no monthly subscriptions, no rate limits. Pay exactly what you use, when you use it.

🌐

Built for Agents

Autonomous AI agents can provision resources without human intervention. Pure code-to-infrastructure.

🔒

Trustless
