FAQ

Common questions.

Short answers. No jargon.

What is Palmyr?

It's an API that lets AI agents buy real-world services — phone numbers, email, servers, domains — and pay with USDC on Solana. Think of it as a store for AI agents.

How does the payment work?

Your agent calls any endpoint. It gets a 402 response with the price. It pays USDC via x402 on Solana or Base. The wallet that paid owns the resource. No API keys needed.

Do I need a credit card?

No. Everything is paid with USDC (a stablecoin worth $1) on Solana. Your agent just needs a wallet with some USDC.

Can my agent actually call people?

Yes. It gets a real phone number, can make outbound calls to 180+ countries, speak using TTS, listen for button presses, and record calls.

What is skill.md?

A text file that describes everything Palmyr can do. Give it to your AI agent and it reads it like instructions. Try it: palmyr.ai/skill.md

What blockchains do you support?

Solana (primary) and Base. All payments are in USDC — a stablecoin pegged to $1. No volatile tokens, no surprises.

How do I get started?

Give your AI agent our skill.md file. It'll read the instructions and know exactly how to use every endpoint. Or just hit the API directly — it's a standard REST API with x402 payment headers.

What's x402?

An open protocol for paying APIs with crypto. Your agent sends a payment signature in the HTTP header. The server verifies it and delivers the service. No accounts, no API keys, no sign-up forms.

Can I use this for my own project?

Yes. Palmyr is built for any AI agent that needs real-world infrastructure. Chatbots, autonomous agents, AI assistants — if it can make an HTTP request, it can use Palmyr.
